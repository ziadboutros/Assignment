Personal Portfolio Page
Created by Ziad Boutros

This project is a single-page personal portfolio built using semantic HTML5 and custom CSS.

The page includes:
- Introduction
- About Me
- Hobbies
- Skills
- Contact form

The project follows a clear file structure with separate folders for CSS and images. It also includes accessible features such as meaningful image alt text, properly associated form labels, and a logical heading structure.

The website was designed with a consistent visual style, clean spacing, simple navigation, and responsive image sizing.

No CSS frameworks or JavaScript were used.
